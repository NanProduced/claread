# Product

## Register

product

## Users

Claread Web 面向希望在浏览器中真正读懂英文文章的中文用户。核心用户包括大学生、备考用户、职场阅读者、研究与行业材料阅读者，以及已经通过轻入口完成初步解读、希望在更完整界面里复看、整理、导出和沉淀理解的人。

这些用户来到 Web，并不是为了进入一个资料后台，也不是为了围绕 AI 对话。他们来到 Web，是为了在更大的屏幕、更长的会话和更稳定的版面里，把一篇英文文章读透，并把这次理解保存成可回看、可分享、可导出的成果。

Claread Web 的用户通常处在三类连续场景中：

- **进入场景**：带着一篇英文材料进入 Claread，想快速开始阅读与解读。
- **工作场景**：在 Reader 中精读、查词、看语法、看句子拆解、加高亮、写笔记。
- **沉淀场景**：回看历史、整理词汇、导出产物、分享结果，或未来通过产品页继续理解 Claread 的能力。

## Product Purpose

Claread Web 是 Claread 在浏览器中的完整产品形态，不是小程序放大版，也不是当前功能页集合的临时壳。它共享通用后端、canonical result 和 render scene，用统一的设计语言承载 Reader、功能页、未来产品页、分享页、导出页与内容型页面。

Web 的第一性体验是“透读英文文章”。用户进入 Claread Web 后，最核心的感受应该是：这是一套围绕文章本身组织起来的阅读系统。文章是舞台中心，词汇、语法、句子拆解、笔记、导出与分享都围绕文章展开。无论是任务入口页、Reader、分享页还是未来产品页，都必须服务这一核心认知，而不是把 Claread 变成一个通用工作台、学习后台或 AI chat 界面。

Reader 是 Claread Web 的品牌现场，但不是唯一现场。它最完整地体现 Claread 的能力和气质；与此同时，功能页、产品页和导出分享页也必须说同一门设计语言。开发顺序可以分先后，设计纲领不能分主次。产品页只是后开发，不是后设计。

Reader 只有两种模式：

- **精读模式**：主工作模式。以批注感、校读纪律和结构化理解为核心。
- **沉浸模式**：回到文章。以段落优先、杂志式开场和更安静的阅读感为核心。

模式切换表达阅读意图，不是显示 preset。阅读设置只负责排版与主题微调，不负责反向拼出模式效果。

## Brand Personality

Lucid, Editorial, Instrumental, Tactile.

Claread Web 的品牌不像一个效率工具，也不像一个营销网站。它更像一张被认真整理过的编辑台，或者一份仍在工作中的长杂志母本：结构清楚、语气克制、细节有判断、离文字很近。

- **Lucid**：复杂英文必须被照亮、被分层、被讲清楚。
- **Editorial**：界面像被编辑过，而不是把能力堆出来。
- **Instrumental**：工具为阅读服务，不抢舞台，不制造噪音。
- **Tactile**：允许有纸面、旁注、印记、引线的触感暗示，但必须克制，不能滑向拟物装饰。

Claread Web 的文化气质应保持 `60%` 学术骨架与 `40%` 文学气味。它更接近 LRB、The Atlantic、Aeon 这一类长杂志的阅读感，而不是冷白学术期刊，也不是文学封面的情绪化编排。

## Anti-references

- 不做 Web 版小程序拉伸。
- 不做 SaaS 管理后台式侧边栏 + 卡片网格。
- 不做可自由拼装的阅读控制台。
- 不做 Word / WPS 式专业编辑器。
- 不做 NotebookLM 式多资料工作台。
- 不把 AI chat 放在 Reader 中心，也不把右侧区域做成批注仓库。
- 不做“暗色后台 + 暖纸补丁”的伪夜读主题。
- 不做用应用壳定义品牌的阅读器。
- 不做学习打卡、排行榜、连续天数、学习小组。
- 不让生词本压过语法、句子和篇章解读。
- 不用纸张纹理、装饰化校对符号、Post-it 拟物贴纸伪装纸面美学。
- 不把产品页当成系统之外的例外页，只因为它开发得更晚。

## Design Principles

1. **全站是一套语言，不是若干页面风格的拼接。** Reader、功能页、产品页、分享页、导出页和未来内容页都必须来自同一母语言。
2. **阅读舞台优先于应用壳。** 应用壳可以存在，但只能像工作台边缘，不得比文章更有存在感。
3. **模式切换是阅读意图，不是显示预设。** 精读与沉浸是两种阅读目的，不是一个控制面板调出来的两组配置。
4. **沉浸模式是独立投影，不是精读减配。** 它必须回到段落、篇章和杂志式开场，而不是简单隐藏几层信息。
5. **主题是整体设计语言，不是背景皮肤。** `纸质 Paper` 是母主题，`浅色 Light` 与 `深色 Dark` 是同一语法下的浓度调节。
6. **标注是 Claread 的核心价值，不是可有可无层。** 在精读模式里，标注、句后批注、引线和结构解释必须被清楚看见。
7. **功能页继承纪律，不继承戏服。** Reader 的抽象规律应扩散到全站；显性批注符号语言则应克制使用，只在真正贴近阅读的地方出现。

## Accessibility & Inclusion

Claread Web 面向长时间阅读和复杂英文理解，必须优先保证可读性、稳定性和低认知负担。正文、译文、解释、边注与控制区必须有清晰层级；颜色不能作为唯一语义来源；模式切换必须明确、可理解、可恢复。

夜读可读性是正式要求，不是附加皮肤。`深色 Dark` 主题必须保持与母主题一致的结构语言，同时适应夜读环境，避免后台式纯黑界面和高刺激霓虹对比。

沉浸模式与精读模式都要保证稳定阅读体验。沉浸模式不能因为追求气氛而损失可读性；精读模式不能因为承载更多信息而陷入控制噪音。译文、标注、句后卡和用户笔记都必须在可发现、可回看、可撤回的前提下工作。
