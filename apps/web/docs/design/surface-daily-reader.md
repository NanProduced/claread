# Daily Reader Surface

> **状态**: `CURRENT` | **最后验证**: 2026-08-20

Daily Reader 是 Claread Web 的公开刊物 surface。它通过最外层 `.daily-reader-surface` 自包含，不改变登录页、产品页或私有 Reader 的主题与字体。

## 视觉方向

- 暖纸色背景、深墨正文、低频蓝色 accent。
- 用留白、细规则线和排版建立层级，不用卡片堆叠。
- 不使用渐变、玻璃拟态、装饰阴影、大圆角或深色主题。
- 正文列约 `680px`；标题与封面可放宽，但正文不随大屏无限拉伸。

所有颜色、比例、字体和字号通过 `.daily-reader-surface` 下的 `--dr-*` token 消费。其他 route 上不得出现该 class，也不得解析出 `--dr-paper` 等 scoped token。

## 字体

| 角色 | 字体 |
|---|---|
| 英文标题与正文 | Newsreader（`--font-daily-reading-en`） |
| 中文标题与正文 | Noto Serif SC 子集；缺字回退到系统中文衬线 |
| 控件与元数据 | Inter |
| 期号、日期、段号 | IBM Plex Mono |

Daily Reader 的 Newsreader 只由 `--dr-font-en` 消费。全站原有 reading font 继续是 Source Serif 4；不得把 Daily 字体变量重新接回全局工具类。Noto 子集采用 `font-display: swap`，并限制 unicode range，避免拉丁字符触发中文字体下载。

## 标题与封面

详情页标题顺序固定为：刊物/日期 → 中文主标题 → 英文原题 → 中文副题 → 标签与来源元数据。

有合格封面时使用固定版式裁切并只显示真实图说；没有封面时使用同一套 type-poster：纸色抬升面、中文/英文标题与 accent 规则线。禁止输出“No cover”之类开发者文案。`cover_theme` 当前只有 `editorial_warm` 一个兼容值，不是主题选择器，页面不据此制造第二套视觉真相。

## 正文与注解

- 第一段只有在首字符为 ASCII 英文字母时使用 drop cap。
- 段号在移动端位于正常流；中等及以上宽度才可进入边缘位置，不能在 640px 附近被裁切。
- 词汇、短语、语境表达分别用实线、点线和双线下划线；类别不能只靠颜色表达。
- 交互高亮必须有可访问名称、`aria-expanded` 和指向注解元素的 `aria-controls`。
- 桌面注解在右侧边注；移动端成为当前段后的行内注解，并重复目标表达。
- 段落导读、译文和“本篇要点”等普通 callout 使用 1px 中性顶部分隔，不使用厚彩色侧边框。
- 中文译文使用正文级墨色和舒展行高，不做成低对比脚注。

## 学习模式

“浏览 / 学习”是默认展开策略，不是两份内容：

- 浏览：导读和译文按需展开。
- 学习：首次进入时默认展开全部导读和译文。
- 读者可在学习模式中逐项关闭；模式选择通过 localStorage 持久化。
- localStorage 不可用时仍可在当前会话切换，页面不得报错。

所有展开控件使用中文标签，触控目标至少 44px，并保留 `focus-visible` 状态。

## 收藏与登录返回

- 已登录：按钮在原页面执行收藏/取消收藏，失败保留当前状态并提供重试。
- 未登录：收藏链接跳转登录并携带同一文章的 `next` 与 `intent=save`；登录返回后自动收藏一次，再清理 URL intent。
- 会话过期：显示中文安全提示和重新登录入口，不暴露上游错误正文。
- 收藏身份固定为 `daily_reader_article:{articleId}`。

## 响应式与红线

必须至少验证 390px、640px、1440px：无水平溢出，段号可见，注解不遮挡正文，控件可触达。

禁止：荧光底色代替下划线语义、蓝紫渐变、SaaS 式巨型 hero、英文开发占位、同链接双 CTA、无反馈分享按钮、仅 hover 可用的关键操作。

## 验证入口

- Vitest：Daily 学习交互、surface token、语义 token 与公开页面契约。
- Playwright：公开列表/详情、390/640/1440 响应式、学习模式持久化、登录返回自动收藏、SEO/分享回归。
- 生产构建后检查字体请求、console、水平溢出和截图。
